# The Deborahs — Repaired Project

## Run locally

1. Open this project folder in VS Code.
2. Open a terminal in the folder containing `package.json`.
3. Run:

```bash
npm install
npm run dev
```

4. Open the Vite URL shown in the terminal (normally http://localhost:5173/).

Do **not** open `index.html` with Live Server for this Vite/React project.

## Important

If the application uses Supabase, make sure the required `VITE_SUPABASE_*`
environment variables are configured in a local `.env` file.
